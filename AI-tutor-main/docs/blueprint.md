# **App Name**: AI Study Buddy

## Core Features:

- Personalized Learning Paths: Generative AI crafts custom study plans tailored to each student's learning style and goals.
- Adaptive Question Generation: The AI tutor dynamically generates practice questions based on the student's progress and areas needing improvement.
- Progress Tracking: Monitors student performance and provides detailed reports on strengths and weaknesses.
- Interactive Lessons: Offers engaging, interactive lessons with multimedia elements to enhance understanding and retention.
- Header Navigation: Prominent 'Login' and 'Signup' buttons for easy access.

## Style Guidelines:

- Primary color: Soft blue (#89CFF0) to evoke trust and intelligence.
- Background color: Light desaturated blue (#E6F7FF).
- Accent color: A contrasting soft green (#A0E7E5) to highlight key interactive elements.
- Headline font: 'Poppins' (sans-serif) for a modern and friendly look. Body font: 'PT Sans' (sans-serif) to ensure readability.
- Friendly, illustrative icons representing various subjects and learning concepts.
- Clean, modern layout with clear section divisions to showcase app benefits.
- Subtle transitions and animations to enhance user engagement and provide visual feedback.
